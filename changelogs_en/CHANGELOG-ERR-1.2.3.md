# :exclamation: [Endless Rise: Remastered](https://www.curseforge.com/minecraft/modpacks/endless-rise) — Update 1.2.3

---

This update focuses on fixing some important issues and making general improvements to the project. ([Issue №83](https://github.com/BMProjects-Development/Endless-Rise-Remastered/issues/83))

Key features:
1. Added custom mod Gravestone Curios API Compat Backport: Now, when you break a grave, all the accessories immediately move to the correct slots.
2. Updated custom mod Endless Rise Tweaks with fixes some errors and optimization ItemStages mod.
3. Updated custom mod SeasonsHud Tweaks with fixes version of mod.
4. Removed body damage.
5. Changed recipes.
6. Changed quests.
7. Changed tags, now some blocks (blocks from dimension The Bumblezone, melon and pumpkin) can break by hand.

The full list of changes is available below.
