# :exclamation: [Endless Rise: Remastered](https://www.curseforge.com/minecraft/modpacks/endless-rise) — Обновление 1.2.3

---

Данное обновление сосредоточено на исправлении некоторых важных проблем и общем улучшении проекта. ([Issue #83](https://github.com/BMProjects-Development/Endless-Rise-Remastered/issues/83))

Ключевые изменения:
1. Добавлен собственный мод Gravestone Curios API Compat Backport: теперь при ломании могилы все аксессуары сразу переходят в нужные слоты.
2. Обновлён собственный мод Endless Rise Tweaks с исправлением некоторых ошибок и оптимизацией мода ItemStages.
3. Обновлён собственный мод SeasonsHud Tweaks с исправлением версии мода.
4. Убрано получение урона через конечности.
5. Изменены рецепты.
6. Изменены квесты.
7. Изменены теги, теперь некоторые блоки (блоки из измерения The Bumblezone, арбуз и тыкву) можно добывать руками.

Полный список изменений представлен ниже.
