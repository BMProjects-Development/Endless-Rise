# :exclamation: [Endless Rise: Remastered](https://www.curseforge.com/minecraft/modpacks/endless-rise) — Обновление 1.2.2

---

Данное обновление сосредоточено на исправлении некоторых важных проблем и общих улучшений проекта. ([Issue #72](https://github.com/BMProjects-Development/Endless-Rise-Remastered/issues/72))

Ключевые изменения:
1. Добавлен собственный мод Endless Rise Tweaks, исправляющий некоторые ошибки.
   - Добавлен новый способ создания предметов (пока что только для ручной мельницы);
   - Исправлена невозможность добыть рукой ручную мельницу из мода Atum;
   - Убран спавн всей руды из мода Immersive Engineering;
   - Убран спавн дома жителя из мода Immersive Engineering;   
   - Все кастомные предметы перенесы в наш мод.
2. Добавлен собственный мод Polymorph Artisan Worktables для возможности выбора нужного рецепта при их конфликте.
3. Добавлен собственный мод SeasonHud Tweaks для более логического отображения сезонов года.
4. Добавлен официальный сервер сборки в список серверов!

Полный список изменений представлен ниже.
